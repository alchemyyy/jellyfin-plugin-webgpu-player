WebGPU Player

The server offers these decoders and passes to every WebGPU Player client. A client downloads a decoder when a playback needs it, and a pass when its user adds it in the player's settings. An upload replaces the bundled decoder of its id, or the bundled pass file of its name, until it is deleted.

Client defaults

Set the defaults of every WebGPU Player client setting here; a user's own choice wins over them. The audio output device and a user's own decoders stay per browser.

Decoders

Decoder packages (.wasm): GPU video decoders and software audio decoders.

Passes

Pass files (.wgsl): postprocessing passes a user can add to the player's presentation.
